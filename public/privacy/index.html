Data Minimization & Chrome Web Store Compliance

Privacy Policy

Effective Date: November 17, 2026 · Website: https://www.dodx.shop

At Dodx (dodx.shop), protecting your privacy is fundamental. Both the dodx.shop website and the Dodx — Verified Coupons & Store Directory Chrome extension are built to help shoppers discover verified coupons, clip discounts, and official retail offers without collecting, selling, or transmitting personal browsing history.

1. Information Accessed by the Dodx Chrome Extension

The Chrome extension requests strictly minimal Manifest V3 permissions:

  • storage: Stores the public coupons and offers directory JSON (offers.json) locally on your device for fast performance and offline support.
  • alarms: Periodically refreshes the public coupons and offers directory JSON from https://www.dodx.shop/api/offers.json in the background.
  • activeTab: Used only when you click the extension icon to read the active tab's hostname locally in memory so the popup can highlight if you are currently visiting a supported store (such as Amazon, HONOR UAE, AliExpress, or Alibaba). The hostname is never logged, stored, or sent to any server.

2. Personal Data Collection & Selling

The Dodx Chrome extension does not collect, store, transmit, or sell personally identifiable information (PII), browsing history, passwords, form inputs, payment details, or health/financial data.

3. User-Initiated Store & Deal Links

Dodx never runs hidden frames, background cookie stuffing, or silent redirects. Direct store and coupon links are opened strictly when you intentionally click a store, product card, or deal button inside the website or extension at no extra cost to you.

4. Website Analytics

The dodx.shop website uses Google Analytics (G-E4EE0Z7PC8) to understand aggregate page traffic and improve site navigation. The Dodx Chrome extension itself does not run third-party analytics trackers or remote JavaScript code.

5. Data Security & No Remotely Hosted Code

All code executed by the Dodx Chrome extension is packaged locally inside the extension bundle. The extension fetches only pure, sanitized JSON data from https://www.dodx.shop/api/offers.json over HTTPS.

6. Contact Information

If you have any questions about this Privacy Policy, Chrome Web Store compliance, or data handling practices, please contact us at privacy@dodx.shop or via https://www.dodx.shop.
